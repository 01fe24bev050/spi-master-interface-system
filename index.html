Serial Communication Interface (SPI Master Interface)

This project demonstrates a hardware-oriented master–slave serial communication interface for a digital password lock. A 2-bit password is loaded into a parallel-in/serial-out register, transferred with clock pulses, checked by a comparator at the slave, and the access status is sent back to the master through a return channel.

The prototype uses standard 74HC logic ICs rather than a microcontroller, making the data path and control signals visible for learning and verification.

Serial Communication Interface (SPI Master Interface)

01 / The master enters a two-bit password using input switches.

02 / A 74HC165 PISO register captures the parallel password.

03 / The active-LOW LOAD control prepares the register for shifting.

04 / Clock pulses transmit the password serially to the slave.

05 / A 74HC595 SIPO register receives the incoming serial bits.

06 / The latch edge updates the slave's parallel output pins.

07 / A 74HC85 magnitude comparator checks the received code against the stored code.

08 / Logic gates derive the access-granted or access-denied status.

09 / A second 74HC165 and 74HC595 form the slave-to-master return path.

10 / LEDs show the final status at the master; a counter-based controller can sequence the operations.
