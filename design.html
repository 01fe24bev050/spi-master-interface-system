Every component, both paths.

↗ Master → Slave · Password

Master DIP switches→U1 · 74HC165 PISO
NE555 clock+74HC161 counter→SCLK / SH-LD control
Serial MOSI→U2 · 74HC595 SIPO→74HC85 comparator

The master password is loaded in parallel into U1, shifted serially to U2, then presented for comparison with the preset password at the slave. The latch pulse updates the SIPO outputs.

Slave output: match / mismatch

↙ Slave → Master · Status return

74HC85 result→74HC32 OR logic→U6 · 74HC165 PISO
Serial MISO→U7 · 74HC595 SIPO→Master LEDs
NE555 clock+74HC161 counter→return LOAD / LATCH

The comparator decision is encoded by the logic stage, loaded into U6, shifted back on MISO, captured by U7, and displayed by the master LEDs. Slave LEDs can show the local result if connected in the physical design.

Transaction sequence.

01

Capture password

DIP switches set the two-bit input; LOAD captures it into the master PISO.

02

Transmit to slave

Clock pulses shift the bits across the serial link; the slave SIPO captures them.

03

Compare

A latch edge updates the slave outputs; the comparator and mismatch logic decide the status.

04

Return and display

The slave PISO sends the status back; the master SIPO latches it and drives the LEDs.
