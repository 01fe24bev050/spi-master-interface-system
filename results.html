Evidence checklist.

01 / Forward path

Confirm two password bits leave U1 and are captured by U2 in the intended bit order.

02 / Comparator

Confirm A=B is asserted only for a matching password and mismatch logic drives the deny state.

03 / Return path

Confirm status is loaded into U6, shifted back, received by U7 and latched at the master.

04 / LEDs

Verify only the intended green or red indicator is active after the full transaction.

What this project demonstrates.

Reduced data wiring

Serial communication transfers bits over a data line plus timing/control.

Sequential control

LOAD, clock and LATCH demonstrate timing-sensitive digital design.

Bidirectional interface

The result is returned to the master instead of being shown only at the slave.
