Why this project?
What does it solve?

Understand the problem, expected outcome and the key difference between parallel and serial communication.

Reducing wires while keeping control visible.

A digital password lock needs to transfer user-entered data to a slave-side checking circuit and return an access decision to the master. Direct parallel communication requires multiple data wires, while a serial interface can send data over fewer signal lines. The challenge is to coordinate data loading, clocked shifting, output latching, comparison and return-status handling using discrete logic ICs without a microcontroller.

Project objective

Design and demonstrate a two-way master–slave digital password-lock interface using PISO/SIPO shift registers, comparator logic, clock and control signals, and status LEDs.

What the system should demonstrate.

01

Forward transfer

Master password is loaded in 74HC165 and serially transferred to the slave's 74HC595.

02

Password validation

74HC85 compares the received value with the predefined password.

03

Return status

Slave sends an encoded status back through the second PISO/SIPO pair.

04

Visible indication

The master updates green/red indicators after the returned status is latched.
